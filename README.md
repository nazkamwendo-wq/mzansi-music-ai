# Mzansi Music AI

Modern AI-powered music generator focused on South African genres.

**Features:**
- Create original tracks from text descriptions in Amapiano, Gqom, Maskandi, Gospel and more
- Offline Beat Maker with Web Audio synthesis (works on low-data phones)
- Local song library (saved in browser)
- Your music, your rights — download and use commercially
- Dark, modern UI optimized for mobile

Built as a fully functional upgrade of the original Lovable project.

## Deploy

This is a static site. Deploy to Netlify, Vercel, or GitHub Pages by pointing at the root.

## Local

Open `index.html` in any browser.
